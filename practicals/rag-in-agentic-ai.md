# 🛠️ Practical: Building a Simple Agentic RAG Workflow

In this practical exercise, we will use Python along with industry-standard frameworks (`LangChain` and vector databases) to build a foundational Agentic RAG system.

> **Prerequisite:** Ensure you have your OpenAI API key or a compatible local LLM environment configured.

---

### Step 1: Install Required Libraries

```bash

```

### Step 2: Python Code for Agentic RAG
Below is a clean, production-ready Python script that initializes a vector database (our private knowledge base) and equips an agentic retrieval chain with search capabilities.

```python
import os
from langchain.chains import create_retrieval_chain
from langchain.chains.combine_documents import create_stuff_documents_chain
from langchain_community.vectorstores import FAISS
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 1. Setup your API Key (Replace with your actual key or use environment variables)
os.environ["OPENAI_API_KEY"] = "your-openai-api-key-here"

# 2. Mock Private Knowledge (Imagine this is your University's new AI Policy document)
university_policy = """
University AI Policy 2026:
- Students are allowed to use Agentic AI tools for brainstorming and coding assistance.
- All code generated by AI must be explicitly cited in the bibliography.
- Direct copy-pasting of AI-generated essays without modification is strictly prohibited and counts as plagiarism.
- Final year projects must include a section explaining how agents were evaluated.
"""

# 3. Process the document (Chunking and Embedding)
text_splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=20)
docs = text_splitter.create_documents([university_policy])

# Create a vector database (memory store)
embeddings = OpenAIEmbeddings()
vector_store = FAISS.from_documents(docs, embeddings)
retriever = vector_store.as_retriever(search_kwargs={"k": 2})

# 4. Set up the LLM
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 5. Create the RAG Prompt
system_prompt = (
    "You are an assistant for question-answering tasks. "
    "Use the following pieces of retrieved context to answer "
    "the question. If you don't know the answer, say that you "
    "don't know.\n\n"
    "{context}"
)
prompt = ChatPromptTemplate.from_messages([
    ("system", system_prompt),
    ("human", "{input}"),
])

# 6. Build the RAG Chain (The Agentic Component can orchestrate this)
question_answer_chain = create_stuff_documents_chain(llm, prompt)
rag_chain = create_retrieval_chain(retriever, question_answer_chain)

# 7. Ask the Agentic RAG system a question
response = rag_chain.invoke({"input": "Can I copy-paste an AI-generated essay directly?"})

print("--- Answer from Agentic RAG ---")
print(response["answer"])
```
